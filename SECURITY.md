# Segurança

## Princípios deste projeto

- Não inclua chaves, tokens, senhas, arquivos `.env` ou dados pessoais no repositório.
- Os registros de estudo são armazenados apenas no navegador (`localStorage`). Faça backup em JSON somente em local confiável.
- Antes de compartilhar uma captura de tela ou backup, remova links privados, currículo e anotações pessoais.
- Dependências externas não são necessárias para a interface publicada.

## Relatar um problema

Não abra uma issue pública com credenciais ou dados sensíveis. Remova a informação sensível e entre em contato com o responsável pelo repositório por um canal privado.
