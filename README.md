# Rota Dev — Plano de Estudos

Painel estático e pessoal para acompanhar estudos de C, Python, algoritmos, Git, backend e preparação para estágio.

## Recursos

- tarefas, trilhas, progresso, revisões e exercícios;
- registro local de tentativas, dificuldades e projetos;
- laboratório de lógica com dicas graduais e feedback sem solução completa;
- agenda semanal, cronômetro de foco, notas e exportação de CSV/JSON/PDF;
- checklist de estágio e links do GitHub.

Os dados de uso ficam no `localStorage` do navegador. Use o backup em JSON antes de trocar de computador ou navegador.

## Executar localmente

Abra `dist/index.html` no navegador.

## Publicação

O fluxo `.github/workflows/deploy-pages.yml` publica automaticamente a pasta `dist/` no GitHub Pages a cada envio para a branch `main`.
